# Token-lean: search first, read little, filter always

## Habits
1. Search before you read. Use a content search to find the right file and line, then read only that range.
2. Read only the sections a task needs. Reuse facts already read in this session.
3. Filter tool output before printing it: last 15 lines of a build, only passed and failed lines of a test run, a count instead of a list.
4. Never paste a raw email thread, a full log or a whole file when a summary answers the question.
5. Run independent commands in parallel in one step.
6. Save decisions, results and next actions to a notes file before a long task ends, so a fresh session can continue.
7. Suggest a fresh conversation when the current one is long and the next task is unrelated.

## Targets
Routine checks: about 1,500 tokens of tool output. Larger output is fine when evidence requires it.

## Never
Never drop a mandatory instruction to save space. Keep full sources on disk.

## Done means
The answer is correct and the session used the least context that proved it.
