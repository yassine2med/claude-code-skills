# Recruiter reply: short, warm, approved

Reply to every real job email. Skip only automated acknowledgements. Every reply needs the user's yes on the exact text.

## Draft
1. Read only the latest message, not the whole thread.
2. Layout: "Hi Name," alone on the first line, a blank line, short paragraphs with blank lines between, then a closing and the signature. Never one block of text.
3. State only facts the user has given you. Never guess pay, dates or legal details: ask.
4. Show the draft and wait for the yes (see `approval-gate`).

## By type
- **Rejection or position filled:** thank them, say the user would be a strong candidate, ask to be kept in mind. If they name a gap the user truly covers, clarify it truthfully.
- **Requirement the user does not meet (clearance, location, license):** stay warm, say it once, ask them to keep the resume for roles without it. Do not argue.
- **"Apply on our portal":** thank them, say the user will apply, and add a same-day reminder to do it.
- **A proposed time:** add a reminder with the clock time, then run `interview-prep`.
- **A missed call:** apologise briefly and say the user was busy. Offer two new times.

## Send (after the yes)
Send in the same thread as a reply, not a new email. Attach the resume if asked. Check the sent copy kept its line breaks. Label the thread as answered and log it.

## Never
Never send without approval of the exact text. Never reply to a different address than the sender's. Never paste a raw thread into the chat.

## Done means
The message is in the Sent folder, in their thread, labeled, and logged.
