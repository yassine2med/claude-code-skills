# Company research: five lines, cheap, sourced

## What the user needs (and nothing more)
1. What they do and for whom.
2. Size and location (office, hybrid or remote).
3. News from this year: funding, layoffs, contracts won.
4. Who the user would talk to: name, title, background.
5. The honest read: fit, risk, and one opening line the user can say.

## Steps
1. Check what is already known: past emails, notes, saved job rows.
2. Read the company's own site: About, Careers, Team. One fetch each. Read the text, not a screenshot.
3. One web search for news, one for the person. Reading is free. Never connect or message anyone without the user's yes.
4. Stop at about five tool calls. If it is still unclear, say what is unknown.

## Is it legit? (a recruiter or a posting)
Red flags: a free-mail sender for a "company", pay far above market, a request for ID, bank details or a fee, a "check to buy equipment", interviews by chat only, a domain registered this year.
Two flags: tell the user plainly and do not reply until they decide.

## Rules
- Every fact carries its source in a few words ("their Careers page"). A guess is marked as a guess.
- Never put private details of the user into a search or a form.
- Save what lasts: the five lines go into the interview brief or the job tracker note.

## Done means
Five lines with sources, saved where the next step will read them.
