# Interview prep: from invitation to thank-you

## The moment a time appears
1. Check the calendar for conflicts and travel. Never accept a time the user cannot keep.
2. Create the calendar event with the link or address and the interviewer's name.
3. Set a reminder that carries the clock time, 60 and 15 minutes before.
4. Update the job tracker: status Interview, next step date.

## Build the brief (30 minutes, once)
1. The company: five lines from the `company-research` skill.
2. Fit: map the posting's top five requirements to the user's real experience. Mark gaps honestly.
3. Answers in STAR form, three lines each: situation, what the user did, result with a number. True stories only. Never invent a number.
4. Keep a story bank: six stories cover most questions (a win, a mistake, a disagreement, a deadline, a time you learned fast, a time you helped someone).

## Practice
Ask one question at a time from the brief. After each answer give three things:
1. One thing that worked.
2. One thing to cut.
3. A tighter version in the user's own words.
Push on vague answers: "What was the number?" Five questions make one session.

## Questions that need the user's own answer
Pay expectations, work authorization, reasons for leaving, start date. Ask the user before the call. Never invent an answer. Never speak badly of a past employer.

## After
1. Send a thank-you note the same day (draft, the user approves, then send).
2. Log what was said and the next step.
3. Set a follow-up reminder for the date the interviewer named.

## Done means
The event and reminder exist, and the brief has no empty answer line for the first five questions.
